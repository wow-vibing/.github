# wow-vibing

Tooling and custom content for **World of Warcraft: Wrath of the Lich King 3.3.5a (build 12340)** private-server modding,
built on [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk) and its Lua engine [mod-ale](https://github.com/azerothcore/mod-ale).

What we work on:
- **Encounters**: boss and dungeon scripting in Lua (mod-ale), designed for 5-player groups
- **Client asset pipeline**: custom audio → DBC rows → MPQ client patches, with a byte-exact custom WDBC writer
- **AI-assisted workflow**: a [Claude Code](https://claude.com/claude-code) setup with safety hooks, skills and specialised agents

The main workspace is private to members. No Blizzard game files are distributed by this organization.
